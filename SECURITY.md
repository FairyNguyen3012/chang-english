# Security

Chặng English is a static, single-page app. It has no server, no accounts and no database; everything a learner saves (progress, review notebook, stories, settings) stays in that learner's own browser storage.

## Protections in place

- **Content Security Policy** (`index.html`, generated by `scripts/build.py`):
  - `script-src` allows only the app's own inline script, pinned by its SHA-256 hash. Injected scripts and inline event handlers (`onerror=`, `onclick=`…) are refused.
  - `connect-src 'none'`: the page cannot send data anywhere.
  - Fonts only from Google Fonts; no frames, plugins, workers, form submissions or `<base>` changes.
  - `upgrade-insecure-requests`.
- **Output escaping:** all learner text, saved stories and AI replies are HTML-escaped before display; the app never uses `eval` or builds code from strings.
- **Stored-data validation:** values read back from `localStorage` are type-checked and replaced with safe defaults when malformed.
- **Referrer policy** `no-referrer`: the page address is not sent to third parties.
- **Microphone** is used only after the learner presses a speaking button, through the browser's own permission prompt, and audio is processed by the browser's speech service, not by this app.

## Limits of GitHub Pages

GitHub Pages does not allow custom HTTP headers, so `frame-ancestors`, `Permissions-Policy` and HSTS preload cannot be set. If you need them, serve the site through a host that supports headers (for example Cloudflare Pages or Netlify) and add:

```
Content-Security-Policy: frame-ancestors 'none'
Permissions-Policy: camera=(), geolocation=(), payment=(), usb=(), microphone=(self)
X-Content-Type-Options: nosniff
Referrer-Policy: no-referrer
```

## Reporting a vulnerability

Please report security issues privately through this repository's **Security → Report a vulnerability** tab rather than in a public issue.
